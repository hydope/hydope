I build AI tools that do the work — not demos, working software. Everything below is open source, free to run, and shipping.

## ⚒️ [ShortSmash](https://github.com/hydope/shortsmash) — my flagship
![stars](https://img.shields.io/github/stars/hydope/shortsmash?style=flat-square&v=20261021) ![license](https://img.shields.io/github/license/hydope/shortsmash?style=flat-square) ![ci](https://github.com/hydope/shortsmash/actions/workflows/ci.yml/badge.svg)

**Prompt in. Finished short out.** An AI video studio with eyes: AI script, neural voiceover in 50 languages, AI-verified stock footage (a CLIP + vision gate rejects bad matches before they render), karaoke captions, and one-click publishing to 10 platforms through their official APIs. Web Studio + MCP server included, so AI agents can drive the whole factory.

![ShortSmash Studio publish flow](https://raw.githubusercontent.com/hydope/shortsmash/main/demo/studio-publish-flow.gif)

## 🥽 [POVCut](https://github.com/hydope/povcut) — Ray-Ban Meta POV editor
![stars](https://img.shields.io/github/stars/hydope/povcut?style=flat-square&v=20261021) ![license](https://img.shields.io/github/license/hydope/povcut?style=flat-square)

`pip install povcut` → point it at your glasses footage: AI moment ranking, face-following 9:16 cuts, captions, ready-to-post packs. Plus `povcut spin`, which rewrites any clip into Meta's Spin View structure.

## 📎 [chunkcite](https://github.com/hydope/chunkcite) — verifiable RAG citations
![stars](https://img.shields.io/github/stars/hydope/chunkcite?style=flat-square) ![license](https://img.shields.io/github/license/hydope/chunkcite?style=flat-square) ![ci](https://github.com/hydope/chunkcite/actions/workflows/ci.yml/badge.svg)

Structure-aware chunking for RAG: chunks at headings, tables kept whole, every chunk stamped with heading path and line range — then each claim is checked against its cited chunk, offline, no LLM judge, no API key.
